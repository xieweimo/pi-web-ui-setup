# reconnect（重连）

**独立插件**，与「同步」（`piwork-tools-plugin`）无关，只负责断连恢复。

## 用途

| 操作 | 做了什么 |
| --- | --- |
| 重新连接（刷新本页） | 浏览器重新加载，WebSocket 重新握手 |
| 重启网页服务 | 服务端 POST 本机守护进程 `127.0.0.1:8788/restart`，由它停掉并重新拉起 8787，随后页面自动刷新 |

页面顶部会显示两行状态：

- 网页服务：在线（能看到这个页面就说明连上了）
- 重启守护：已就绪 / 未运行（未运行时「重启网页服务」按钮禁用，关掉页面重新运行「启动 Pi 网页版」即可拉起守护）

## 两个入口的分工

| 场景 | 用谁 |
| --- | --- |
| 页面还能打开，想手动重连/重启 | 本插件的「🔄 重连」页 |
| 页面已经断连（连服务都连不上） | 前端补丁注入的浮层（`patches/patch-pi-web-ui-recovery-ui.js`），出现在右下角 |

## 端口

- 8787：pi-web-ui 网页服务；
- 8788：重启守护（`scripts/pi-web-ui-recovery-watchdog.js`，仅监听本机回环）。

浏览器不直连 8788 —— 重启请求经本插件服务端路由转发，避免跨源与 CORS 问题。

## 安装

```bash
node scripts/install-plugins.js --only reconnect
```

之后刷新网页（或 设置 → 界面插件 → 重载）。
