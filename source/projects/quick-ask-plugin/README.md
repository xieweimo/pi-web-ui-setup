# 临时问问（quick-ask）

顶栏的「💬 临时问问」会打开独立浮层，用当前主对话选中的模型回答一个临时问题。

## 隔离规则

- 通过 `pi --no-session` 运行：不读取、不创建、不续写当前任务或任何历史会话。
- 通过 `--no-tools` 运行：临时问答不能执行命令、读写文件或调用其他工具。
- 主任务继续运行，不会被 steer、暂停或追加消息。
- 面板关闭后结果仅留在浏览器内存；服务重启或刷新页面后消失。

## 使用

1. 主对话中先选好模型。
2. 点击顶栏「💬 临时问问」。
3. 输入问题，按 `Ctrl+Enter` 或点击「发送」。
4. 关闭面板即可丢弃本次临时问答。

## 限制

- 当前只支持标准 `pi` 引擎；若当前模型的凭证不可用，会显示 pi 的原始报错。
- 每次问答最多 5 分钟，超时自动停止。
